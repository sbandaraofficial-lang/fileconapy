# **App Name**: FileHaven

## Core Features:

- File Upload: Users can upload files of various formats to their personal storage. IMPORTANT: Make the functionality and UI simple without any fancy stuff. Just the basic functionality: upload, download, list files and delete.
- File Listing: Display all the files in a structured and paginated list, with details like name, size, and upload date. IMPORTANT: Make the functionality and UI simple without any fancy stuff. Just the basic functionality: upload, download, list files and delete.
- File Download: Enable users to download files to their local device. IMPORTANT: Make the functionality and UI simple without any fancy stuff. Just the basic functionality: upload, download, list files and delete.
- File Deletion: Allow users to delete files they no longer need. IMPORTANT: Make the functionality and UI simple without any fancy stuff. Just the basic functionality: upload, download, list files and delete.

## Style Guidelines:

- Primary color: Forest green (#38A3A5) for a sense of growth and organization.
- Background color: Light beige (#F5F5DC) provides a clean, uncluttered feel.
- Accent color: Teal (#64CCC9) is used for interactive elements and calls to action.
- Body and headline font: 'Inter' for a clean, modern user interface.
- Use a consistent set of minimalist icons for file actions.
- Files are organized in a clear list, and uploaded files are visually distinct.
- Use subtle animations to provide visual feedback during file operations like upload, download and deletion.
